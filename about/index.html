04 / Projects

Things I've built

Side project · Backend

URL Shortener API

View on GitHub ↗

A URL shortening service built the way I like to build things: small on the surface, careful underneath. Give it a long link and it mints a short code, stores the mapping, and sends visitors straight to the original with a 302 redirect.

  • Two-endpoint REST API — POST /url/code creates a short link; GET /url/{code} resolves and redirects.
  • Collision-safe codes — seven random characters from a 62-character alphabet using SecureRandom, with a unique database constraint and retry-on-duplicate writes.
  • Defensive validation — HTTP/HTTPS and host checks on every URL, plus a global exception handler that maps bad input to 400 and unknown codes to 404.
  • Real persistence — MySQL through Spring Data JPA, with a clean controller → service → repository split.
