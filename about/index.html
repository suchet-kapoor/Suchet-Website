Hi, I'm Suchet 👋

Software engineer in Bangalore, India. I build backend systems in Java and Spring Boot, ship them on AWS, and increasingly teach AI agents to do grunt work.

The intent behind my work

For the last three years I've been building and maintaining enterprise full-stack services — the kind of systems where "it works on my machine" is never the finish line. I've built backend functionality from scratch across business modules like HR, Finance, and Payments, and contributed end-to-end on consumer products.

The project that shows that end-to-end span best: Amazon Ring. I worked on the enhanced live view & detection experience — Claude for the intelligence layer, S3 and RDS for data, REST API development, CI/CD pipelines with Vercel, and handling client queries plus the connection to real devices in people's homes. A slice of that work is public on GitHub.

The part of engineering I care most about is the observable kind: a query that gets faster, memory that stops leaking, a code path that stops being a bottleneck. Performance and reliability are features, not afterthoughts — which is also what pushed me to write about processors and databases on this site.

Lately I've been going deep on agentic AI — Claude, Copilot, Codex, MCP, custom agents — not as a buzzword, but as an actual multiplier: wiring agents into real development workflows, logging, and testing loops.
